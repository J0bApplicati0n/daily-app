# День за днём — Android-приложение

Простой **офлайн-ежедневник** на русском языке. Без регистрации, рекламы, внешних сервисов и разрешений на доступ к интернету.

## Возможности

- **Дела:** один постоянный список; ручное добавление и редактирование; ежедневно новые галочки; история отметок хранится на устройстве.
- **Таблеточница:** отдельный список лекарств; кнопки **+** и **−** для ручного счётчика дней приёма; редактируемые дата начала и длительность; расчёт **планового последнего дня** по формуле `дата начала + длительность − 1 день`.
- Данные автоматически сохраняются в локальных настройках Android (`SharedPreferences`), без аккаунта и облака.
- Долгосрочный приём: счётчик не ограничен длительностью, случайное уменьшение ниже нуля невозможно.

**Важно:** счётчик является ручным, не подтверждает фактический приём. Плановая дата окончания не меняется от нажатия +/− и не учитывает пропуски или назначенные врачом изменения схемы. Не прекращайте или не продлевайте лечение только на основании этой даты.

## Получить APK с помощью GitHub — без Android Studio

1. Создайте новый **пустой публичный или приватный репозиторий** на GitHub.
2. Загрузите **содержимое** этой папки в корень репозитория, включая скрытую папку `.github` (в веб-интерфейсе GitHub выберите **Add file → Upload files** и загрузите файлы с сохранением структуры; надёжнее воспользоваться `git` в инструкции ниже).
3. Откройте **Actions → Собрать APK → Run workflow**. Если появится предложение включить Actions, включите.
4. Дождитесь успешного выполнения workflow. Откройте запуск, в разделе **Artifacts** скачайте `DenZaDnem-APK`.
5. Распакуйте ZIP с артефактом — внутри `app-debug.apk`. Передайте APK на Android-телефон (USB, Telegram, Drive или напрямую из GitHub) и откройте. При необходимости разрешите установку приложений из этого источника.

### Надёжная загрузка через Git с ПК

Откройте терминал **внутри папки DenZaDnem**:

```bash
git init
git add .
git commit -m "Initial Android app"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

Замените URL адресом своего нового репозитория. Для отправки может потребоваться авторизация через GitHub Desktop или Git Credential Manager.

## Сборка на компьютере

Требуется Java 17, Android SDK Platform 35, Gradle 8.9 и Android Gradle Plugin 8.7.3. Можно открыть эту папку в Android Studio и выбрать **Build → Build APK(s)** либо выполнить `gradle :app:assembleDebug`.

## Ограничения и хранение

- Удаление приложения или очистка его данных может стереть списки; экспорт/импорт ещё не реализован.
- Приложение не отправляет медицинские данные в сеть.
- При переустановке APK **поверх старой версии** с той же подписью обычно сохраняются данные. Debug APK, собранные на разных компьютерах или CI, могут иметь разные подписи: в этом случае обновление может потребовать удаления старой версии с потерей локальных данных.
- Это исходный проект, а не готовый собранный APK: файл APK создаёт GitHub Actions или Android Studio.
